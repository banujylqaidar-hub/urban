Pac-Man

 Описание проекта

Pac-Man — это классическая аркадная игра, разработанная на языке Python с использованием библиотеки Pygame.

Цель игры — собрать все точки на игровом поле, избегая призраков. Игрок может собирать бонусы, получать дополнительные очки и переходить на следующие уровни.

 Возможности игры

Три уровня с разными игровыми картами.

Три уровня сложности: лёгкий, нормальный и сложный.

Управление персонажем с помощью клавиатуры.

Призраки с разным поведением и алгоритмами преследования.

Бонусные большие точки, позволяющие временно пугать призраков.

Появление бонусной вишни.

Система очков и жизней.

Сохранение рекорда между запусками игры.

Анимации победы и поражения.

Возможность поставить игру на паузу.

 Установка и запуск

Установите Python 3.

Установите библиотеку Pygame:

pip install pygame

Скачайте или клонируйте проект.

Перейдите в папку с проектом.

Запустите игру командой:

python pacman.py

 Правила игры

Собирайте маленькие точки, чтобы получать очки.

Собирайте большие точки, чтобы временно сделать призраков уязвимыми.

Собирайте вишни для получения дополнительных очков.

Избегайте призраков, пока они не испуганы.

Используйте жизни осторожно.

Соберите все точки, чтобы перейти на следующий уровень.

Пройдите все три уровня и одержите победу!
