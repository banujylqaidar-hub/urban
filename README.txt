PAC-MAN — проект на Python + Pygame

Файлы:
- main.py — запуск игры, окно, игровой цикл и обработка событий.
- settings.py — размеры окна, цвета, скорость и карта лабиринта.
- game.py — классы Entity, Player, Ghost и Game; движение, очки, столкновения и отрисовка.

Установка:
    python -m pip install pygame

Запуск:
    python main.py

Управление:
- Стрелки или WASD — движение.
- R — перезапуск после победы или проигрыша.
- Esc — выход.

Код использует ООП и наследование:
Player и Ghost наследуются от Entity.
